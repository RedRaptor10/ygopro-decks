# YGOPRO Decks
A repository containing decks for YGOPRO / EDOPRO.

`character` - Decks for characters from the Yu-Gi-Oh! anime.

`character_anime` - Decks for characters from the Yu-Gi-Oh! anime, containing anime-only cards.

`goat` - Sample GOAT format decks from [https://www.goatformat.com](https://www.goatformat.com/).

`video_game` - Decks from various Yu-Gi-Oh! video games.
